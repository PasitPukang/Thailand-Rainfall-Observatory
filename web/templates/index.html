วิธีอ่านค่า

ผล “วันนี้ฝนจะตกไหม” อยู่ในหน้าภาพรวมและคำนวณจากความถี่วันที่มีฝนย้อนหลัง ส่วนค่าด้านล่างเป็นค่าประมาณปริมาณฝนรายเดือนตามฤดูกาล ไม่ใช่พยากรณ์อากาศสด ช่วงต่ำ–สูงแสดงเปอร์เซ็นไทล์ 10–90 ของ 8 ปีย้อนหลัง ค่าคลาดเคลื่อนเป็นผลทดสอบย้อนหลังแบบเว้นทีละปี

METHOD

คำนวณอย่างไร

  1. รวมฝนรายวันเป็นยอดรายเดือนของแต่ละปี
  2. เลือกเดือนปฏิทินเดียวกับเดือนที่จะประมาณ และใช้เฉพาะปีที่มีข้อมูลครบเดือน
  3. ใช้ค่ามัธยฐานเป็นค่าประมาณ และเปอร์เซ็นไทล์ 10–90 เป็นช่วงอ้างอิง
  4. คำนวณ MAE โดยทำนายแต่ละปีจากปีอื่นอีก 7 ปี แล้ววัดความคลาดเคลื่อน

พิกัดหนึ่งจุดไม่แทนค่าเฉลี่ยทั้งจังหวัด และแบบจำลองย้อนหลัง ERA5 ไม่ใช่ข้อมูลตรวจวัดสถานีโดยตรง

01

Extract · ดึงข้อมูล

Airflow ตรวจวันล่าสุดที่ครบ 77 จังหวัด แล้วเรียก Open-Meteo Historical API ถึงวันที่ย้อนหลัง 7 วัน บันทึกผลดิบเป็น JSON.gz แยกจังหวัดและวัน

02

Cleanse · ตรวจและทำความสะอาด

ตรวจ 24 ชั่วโมงต่อวัน เวลาไม่ซ้ำ เขตเวลา Asia/Bangkok และช่วงค่าฝน อุณหภูมิ ความชื้น และลม แปลงตัวเลขก่อนส่งบันทึก

03

Load · บันทึก PostgreSQL

เพิ่มหรืออัปเดตข้อมูลรายชั่วโมงด้วยคีย์จังหวัดและเวลา แล้วสรุปเป็นข้อมูลรายวัน บันทึกประวัติแต่ละชุดใน etl_batch

04

Validate & Report · ตรวจผลและแจ้งสถานะ

ตรวจจำนวนแถวและความครบถ้วน ส่งออก CSV สำหรับ Power BI และบันทึกสถานะรอบทำงานใน pipeline_run_audit

OPERATING GUIDE

และแหล่งข้อมูล

เส้นทางจากแหล่งข้อมูลจนถึงรายงาน พร้อมตำแหน่งไฟล์และเครื่องมือที่ใช้

01 / START

เปิดระบบ

เปิด Docker Desktop แล้วเริ่มบริการจากโฟลเดอร์โครงการ:

docker compose up -d --build

เว็บนี้เปิดที่ localhost:8090 และ Airflow เปิดที่ localhost:8088

02 / AIRFLOW

ตรวจงานประจำวัน

เข้า Airflow ด้วยบัญชีในเครื่องที่ตั้งค่าไว้ เลือก DAG thailand_weather_daily แล้วดู Grid, Logs และ XCom ของ notify_run_status งานทำงานเวลา 14:00 น. ตามเวลาไทยเมื่อ Docker เปิดอยู่

03 / DATABASE

ดูข้อมูลใน DBeaver

ใช้การเชื่อมต่อ Thailand Rainfall (weather) ที่ตั้งค่าไว้แล้ว ไปที่ weather → public → Tables แล้วเปิดแท็บ Data ของตารางที่ต้องการ

Host 127.0.0.1 · Port 55432 · Database weather
