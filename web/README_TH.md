# คู่มือเว็บวิเคราะห์ฝนและสภาพอากาศรายจังหวัด

เว็บนี้เปิดเฉพาะในเครื่องที่ `http://localhost:8090` และอ่าน PostgreSQL ของโครงการโดยตรง เมื่อ Airflow เพิ่มข้อมูลในฐานข้อมูล ให้กดปุ่มรีเฟรชที่หน้าเว็บเพื่อดูข้อมูลใหม่ ไม่มีการส่งฐานข้อมูลขึ้นเว็บสาธารณะ

## เริ่มและหยุดใช้งาน

1. เปิด Docker Desktop
2. เปิด PowerShell ในโฟลเดอร์ `thailand-rainfall-pipeline`
3. รัน `docker compose up -d --build`
4. เปิด `http://localhost:8090`
5. เมื่อต้องการหยุดบริการ รัน `docker compose stop`

ระบบประกอบด้วย PostgreSQL, Airflow webserver/scheduler และเว็บวิเคราะห์ ใช้พอร์ตในเครื่อง 55432, 8088 และ 8090 ตามลำดับ เว็บจะเปิดได้เมื่อ Docker Desktop และ PostgreSQL ทำงาน

## หน้าเว็บ

| หน้า | สิ่งที่ดูได้ |
| --- | --- |
| ภาพรวมข้อมูล | เลือกจังหวัด, โอกาสฝนตกวันนี้จากข้อมูลย้อนหลัง, ค่าสถิติ 30 วัน, กราฟฝนรายวัน/รายปี/ฤดูกาล, จังหวัดที่มีวันฝนหนักบ่อย |
| แนวโน้มและประมาณการ | ปริมาณฝนรวมรายเดือน 3 เดือนถัดไปจากค่ากลางย้อนหลัง พร้อมช่วงเปอร์เซ็นไทล์ 10–90 และค่าคลาดเคลื่อนย้อนหลัง |
| การทำงานของ Pipeline | ขั้นตอน ETL, สถานะ Airflow, ประวัติ 10 รอบล่าสุดพร้อมจำนวนแถวใหม่/อัปเดต, ตาราง PostgreSQL, จำนวนไฟล์ข้อมูล |
| คู่มือและแหล่งข้อมูล | วิธีเปิดระบบและเครื่องมือ, ดาวน์โหลด CSV/PBIX/เอกสาร, ลิงก์แหล่งข้อมูลและซอฟต์แวร์ |

เมื่อเลือก “เฉลี่ย 77 จุดตัวแทน” ค่าฝนของแต่ละวันคือค่าเฉลี่ยจากจุดตัวแทนจังหวัด ไม่ใช่ปริมาณฝนรวมทั้งประเทศไทย เมื่อเลือกจังหวัด ระบบใช้ข้อมูลจุดตัวแทนของจังหวัดนั้น

## ลำดับการทำข้อมูล

1. Open-Meteo Historical Weather API ส่งข้อมูล ERA5 รายชั่วโมง ณ พิกัดตัวแทน 77 จังหวัด
2. Airflow DAG `thailand_weather_daily` ทำงานทุกวันเวลา 14:00 น. ตามเวลาไทย และโหลดถึงวันย้อนหลัง 7 วัน
3. `extract_raw` บันทึก JSON.gz ใน `data/raw/province_XX/`
4. `cleanse_data` ตรวจจำนวนชั่วโมง เวลาซ้ำ เขตเวลา และช่วงค่าฝน/อุณหภูมิ/ความชื้น/ลม แล้วบันทึกไฟล์ที่ผ่านการตรวจใน `data/cleaned/province_XX/`
5. `load_postgres` บันทึกรายชั่วโมงใน `fact_weather_hourly` และสรุปรายวันใน `mart_weather_daily` แบบ upsert เพื่อไม่ให้แถวซ้ำ
6. `validate_postgres` ตรวจจำนวนแถวและข้อมูลรายวันครบ 24 ชั่วโมง
7. `refresh_powerbi_export` ส่งออก CSV สำหรับ Power BI
8. `notify_run_status` บันทึกจำนวนแถวใหม่/อัปเดตและสถานะใน Logs, XCom และตาราง `pipeline_run_audit`

## วิธีประมาณการ

### วันนี้ฝนจะตกไหม?

เว็บนับวันฝนตก (ฝนสะสม ≥ 0.1 มม.) ในช่วง **±15 วันรอบวันที่ปฏิทินเดียวกัน** ของปี 2018–2025 ถ้าเลือกจังหวัด จะนับเฉพาะจุดตัวแทนจังหวัดนั้น ถ้าเลือกภาพรวม จะนับจุดตัวแทนทุกจังหวัดแล้วแสดงความถี่เฉลี่ยต่อจุด คำนวณโอกาสแบบ `(จำนวนตัวอย่างที่ฝนตก + 1) / (จำนวนตัวอย่างทั้งหมด + 2)` เพื่อลดค่าที่สุดโต่งจากตัวอย่างน้อย และขึ้นข้อความ “มีแนวโน้มฝนตก” เมื่อค่า ≥50% โดยใช้วันที่ปัจจุบันตามเวลาไทย ข้อมูลจริงล่าสุดของฐานข้อมูลแสดงอยู่ใต้ผลลัพธ์

ค่านี้เป็นความถี่ตามฤดูกาลจากข้อมูลย้อนหลัง ไม่ใช่การพยากรณ์สภาพอากาศวันนี้แบบสด และค่าภาพรวมหมายถึงโอกาสเฉลี่ยที่จุดตัวแทนหนึ่งจุด ไม่ใช่โอกาสที่ฝนจะตกที่ใดก็ได้ทั่วประเทศ

### แนวโน้มฝนรวมรายเดือน

เว็บรวมฝนรายวันเป็นฝนรวมของแต่ละเดือน แล้วใช้ข้อมูลปี 2018–2025 ของเดือนเดียวกันเท่านั้น หากเดือนใดข้อมูลไม่ครบจะไม่ใช้ปีนั้น ค่าประมาณคือ **มัธยฐาน** ของยอดฝน 8 ปี ช่วงอ้างอิงคือเปอร์เซ็นไทล์ 10–90 ค่า MAE ทดสอบย้อนหลังโดยเว้นข้อมูลปีหนึ่งออก แล้วประมาณปีนั้นจากปีที่เหลือ ทำซ้ำทุกปี

วิธีนี้เป็นค่าฐานตามฤดูกาล ไม่ทำนายสภาพอากาศจริงในวันที่กำลังจะมาถึง และไม่ใช่ข้อมูลเตือนภัยหรือแบบจำลองพยากรณ์ฝนของกรมอุตุนิยมวิทยา ความคลาดเคลื่อนอาจสูง โดยเฉพาะเดือนที่ฝนผันผวน

## โปรแกรมและเว็บไซต์ที่ใช้

- [Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api) — ข้อมูลย้อนหลัง ERA5

- [เกณฑ์ฝน กรมอุตุนิยมวิทยา](https://www.tmd.go.th/info/%E0%B9%80%E0%B8%81%E0%B8%93%E0%B8%91%E0%B8%AD%E0%B8%B2%E0%B8%81%E0%B8%B2%E0%B8%A8) — ฝนหนักตั้งแต่ 35.1 มม./วัน และหนักมากตั้งแต่ 90.1 มม./วัน
- [Apache Airflow](https://airflow.apache.org/docs/) — จัดลำดับและติดตาม ETL
- [PostgreSQL](https://www.postgresql.org/docs/) — เก็บข้อมูลหลัก
- [DBeaver](https://dbeaver.io/) — เปิดดู PostgreSQL ในเครื่อง
- [Power BI Desktop](https://www.microsoft.com/en-us/power-platform/products/power-bi/desktop) — รายงานข้อมูล

## เมื่อตรวจแล้วข้อมูลไม่อัปเดต

1. ตรวจว่า Docker Desktop เปิดและ `docker compose ps` แสดงบริการ `postgres`, `airflow-scheduler`, `airflow-webserver`, `dashboard` ทำงาน
2. เปิด Airflow ที่ `http://localhost:8088` แล้วดูสถานะ DAG `thailand_weather_daily` ใน Grid หากล้มเหลวให้เปิด Logs ของงานสีแดง
3. หาก Airflow เพิ่งบันทึกเสร็จ ให้กดปุ่มรีเฟรชในเว็บนี้ สำหรับ Power BI Desktop ต้องกด Refresh ในโปรแกรมแยกต่างหาก
4. ข้อมูล ERA5 มีช่วงหน่วง เว็บจึงอาจมีวันล่าสุดย้อนหลังราว 7 วันตามการตั้งค่า Pipeline
